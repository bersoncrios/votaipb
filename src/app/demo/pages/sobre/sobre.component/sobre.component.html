Guia do Administrador

Siga estes passos para criar uma eleição do zero.

1 Etapa 1: Criar Lista de Inscrição Recolher os dados dos eleitores

Antes de criar a eleição, precisa de uma lista oficial de quem pode votar. A forma mais simples é criar uma lista pública e deixar que os eleitores se inscrevam.

  1. Clique no menu Gerênciar Inscrições.
  2. Clique em Nova Lista e dê um título (ex: "Eleição 2024") e uma descrição (opcional).
  3. Após criar, clique no ícone link (Copiar Link) no cartão da lista.
  4. Compartilhe esse link com os seus eleitores/candidatos (via e-mail, WhatsApp, etc.). Eles irão usar esse link para registar o seu Nome e ID.
  5. Quando o prazo de inscrição terminar, clique no ícone download (Descarregar XLS).
info Este ficheiro Excel (.xlsx) será necessário na próxima etapa.
2 Etapa 2: Configurar a Eleição Carregar eleitores e definir cargos

Com o arquivo Excel dos eleitores pronto, seguimos para configuração da votação.

  1. Clique no menu Registrar Eleição.
  2. Preencha os dados básicos.
  3. Na secção de Eleitores, faça o upload do ficheiro Excel que descarregou na Etapa 1.
    Ou, preencha manualmente se preferir
  4. Adicione os Cargos (ex: Presidente) e os respetivos Candidatos.
  5. Clique em "Salvar Eleição" para finalizar.
