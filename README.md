# 🗳️ Vota IPB - Sistema de Eleição

![Status](https://img.shields.io/website?url=https://votaipb.com.br/&label=Status&style=for-the-badge)
![Version](https://img.shields.io/badge/version-1.10.0-blue?style=for-the-badge)
![License](https://img.shields.io/badge/licen%C3%A7a-Propriet%C3%A1ria-red?style=for-the-badge)

**Vota IPB** é um sistema de votação eletrônica seguro e moderno, desenhado para gerenciar as eleições da **Igreja Presbiteriana do Brasil (IPB)**, garantindo integridade, transparência e agilidade no processo.

---

## 🚀 Funcionalidades

### �️ Gestão de Eleições
- **Wizard Passo-a-Passo**: Criação intuitiva de eleições com definição de cargos e membros.
- **Importação de Dados**: Facilidade para importar listas de membros via planilhas (Excel/CSV).
- **Múltiplos Cargos**: Suporte a eleições complexas com diversos cargos simultâneos (Presidente, Vice, Secretários, etc.).

### ⚡ Votação e Apuração
- **Votação Real-Time**: Tecnologia Firebase para registro e contagem instantânea de votos.
- **Escrutínios Automáticos**: Lógica avançada para múltiplos turnos (1º, 2º, 3º escrutínios) com regras de desempate e maioria (50%+1).
- **Voto de Minerva**: Tratamento automatizado para situações de empate persistente.

### 🛡️ Segurança e Controle
- **Painel Administrativo Seguro**: Área restrita para configuração e monitoramento.
- **Autenticação Robusta**: Login seguro para administradores e eleitores.
- **Logs de Auditoria**: Rastreabilidade das ações críticas do sistema.

### 💻 Experiência do Usuário (UX/UI)
- **Design Moderno**: Interface limpa, intuitiva e com suporte nativo a **Dark Mode**.
- **Responsividade Total**: Acesso perfeito via computadores, tablets e smartphones.
- **Feedback Visual**: Notificações claras e indicadores de progresso.

- **🔗 Link de Votação Público** Gere um link de acesso único para a página de votação da eleição.

---

## 🧩 Tecnologias Utilizadas

- **Frontend:** Angular 18+ (Standalone Components)
- **Backend:** Firebase (Firestore, Auth, Cloud Functions)
- **Pagamentos:** Google Pay API
- **Deploy:** Vercel
- **UI Notifications:** SweetAlert2
